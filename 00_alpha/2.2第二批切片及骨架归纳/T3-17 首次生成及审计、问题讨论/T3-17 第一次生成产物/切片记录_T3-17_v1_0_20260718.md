**独立复算实现方式说明（路径独立点）**：
- 数据源独立：`verify/independent_recompute.py` 直读 `entity/input_data.json`，不触碰harness产物。
- 计算核心分叉：
  - stressed值——harness先算固定乘子`vega_mult=1+coef×ΔIV`再逐期相乘；复算用展开式`raw+raw×coef×ΔIV`逐期直接计算（代数等价，表达式路径不同）。
  - band位置——harness用if/elif三分支；复算用嵌套条件表达式（`"below" if... else (...)`）。
  - 双Greek合成——harness用if/else比较链手工取小；复算用内建`min()`。
  - 连续低于槽位计数——harness用命令式for循环+局部变量`consecutive_below`原地累加重置；复算用`itertools.accumulate`+闭包`step`函数做reduce式状态扫描，先batch生成below_flags列表再单独scan，非逐期耦合band/ratio计算的同一循环体。
  四处核心表达式均分叉，非共用同一行；均使用`fractions.Fraction`精确有理数（平凡primitive，允许共用）。
- 手工第三方三角化（人工笔算对触发分支put t5与非触发对照call t4两个关键点做三方核验）：

  ```
  put t5（触发点）：
    raw_vega=30, raw_gamma=1/25；情景乘子 vega_mult=53/50, gamma_mult=109/100
    stressed_vega = 30×53/50 = 159/5 ✓ 与harness/复算一致
    stressed_gamma = 1/25×109/100 = 109/2500 ✓ 一致
    target_vega=477/5, target_gamma=327/2000（t1锚定基线）
    vega_ratio = (159/5)/(477/5) = 159/477 = 1/3 ✓ 一致
    gamma_ratio = (109/2500)/(327/2000) = 4/15 ✓ 一致（327=109×3，化简验证：
      (109/2500)×(2000/327)=(109×2000)/(2500×327)=2000/(2500×3)=4/15）
    combined = min(1/3, 4/15) = 4/15 ✓ 一致；floor=3/5=9/15，4/15<9/15→below_floor
  ```
