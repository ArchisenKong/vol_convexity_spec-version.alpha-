## T0-A · 机器隐喻管辖权与边界（受限隐喻构型，终-11）

**主锚采纳**：机器隐喻为终点态主锚，替代此前未经正式采纳却静默塑造验收语义的"造房子"范式（房＝静态在场验收；机器＝运转履行验收）。采纳形态为受限构型，三件配套如下。

**A-1 管辖权限定**（管三件，不管三件）：
- 管：制品角色分类（T7矩阵）／运行验收语义（履行制，T0-B）／生命周期定位（A-3表）。
- 不管：认识论（归证伪主义，宪法已载）／盈亏评价（归L3证伪器口径）／环境模型（归假设注册制）。

**A-2 四条边界**：
- 边-1 **人机复合**：本机器含人工域与KD裁量位，隐喻不得把终点推向全自动——M4→人工域是设计，不是欠账。
- 边-2 **假设过期非磨损**：机械磨损的对应物＝假设失效/参数漂移/市场态迁移；维保触发源在市场侧，不在文本侧。
- 边-3 **禁作演绎源**：由隐喻推出的任何新结构仍须走一阶反推与登记通道才成立，不因隐喻自洽而自动成立。隐喻是看清目标的镜片，不是生成规矩的模具。
- 边-4 **过程履约≠盈亏结果**：运转合格＝过程履约（各环节按契约履行、留痕对账），不＝盈亏结果；盈亏评价归L3证伪器口径（路径系综、注册反例），与运转验收分属两个判据域。长凸性头寸的正常态＝多数时段小额流血、极少数时段大额兑付——机器完全正常运转的外观在盈亏栏上可长期为亏损，"天天转、天天亏"可能恰是机器最正常的时刻，禁以盈亏读"机器坏了"。

**A-3 生命周期定位表**：

| 站 | 机器语义 | 项目对应 |
|---|---|---|
| 设计定型 | 图纸与工艺定型 | 阶段A文本层完成 |
| 出厂验收 | 出厂检 | G-1（甲∧乙） |
| 试车 | 空转试车／负载试车 | 曳光弹（空转）／两链贯通（负载） |
| 投产 | 正式运行 | 实盘（paper→live分级） |
| 运维改造 | 检修、换件、升级 | 回流环稳态（四类回流） |

终-3"完整运转态"＝投产后带持续运维的稳态。"阶段A完成"与"终点态"关系由此钉死：前者是生命周期一站，后者是稳态。

**A-4 隐喻复议触发**：由隐喻直觉提出的结构候选，若连续两次被一阶反推否决，复议主锚本身（呈KD，同骨架收敛率复议之构造逻辑）。隐喻自身进假设注册制精神管辖，处于与项目其他一切预设相同的可推翻地位。复议计数（“连续两次否决”）载体未指派，随S2入缺口池登记（F4默认）。

## T4 · 回流环（B→A，第三条链）

**深度裁定（KD本轮）**：实证有权修正到思想宪法层。整个循环流＝不断可被事实验证、优化、升级的循环。

四类回流各有成文通道且至少走通一次：
1. **参数回流**：QC/实盘证据→类三槽位取值（校准纪律）。
2. **算法回流**：换装纪律（研究证据→KD裁→版本回写），含§七换装检验协议实测。
3. **规则回流**：实盘经验→交易手册增订。
4. **结构回流**：实证反推修正上层预设，上达宪法层；宪法再版→对照表联动→L2三承载再版→字段层，即回路穿过链①闭合。程序层先例已有一手实例（裁决90-2一阶反例推翻构造侧类一定案，IND5-23）。

**回流环的施工约束**：环上一切结构修改（换桩、新根、schema修订、宪法再版）按元层语法（骨架已归纳形态族＋归纳程序纪律＋换装纪律）执行；元层稳定是回流环安全运转的前提。

**QC⇄IBKR互证**：同一策略状态在两环境的对账口径成文（差异容差、归因路径）。

### T6-1 骨架三重身份（KD本轮confirm）＋母机读法（终-13）
1. **收敛指示器**：G-1甲分量＝骨架稳定N=2；骨架不动＝构造语法归纳完毕。

**母机读法**：元层制品＝制造策略机器的母机，履行制（T0-B）同样施加于元层——母机也须有履行记录（如：归纳程序已履行五批；换装纪律履行次数属现状事实，S2核实登记）。G-1两分量在此读法下一次说清：甲＝母机定型（工装收敛），乙＝产品出厂检（文本贯通）。

### T6-3 治理机制转换

## T7 · 制品角色任职矩阵（六角色×五活动，终-14）

**判别标准（消费关系测试）**：制品X的角色由"哪个生命周期活动消费它、X缺位时哪个活动停摆"判定，不由题材/标题判定。分类是制品×活动的任职关系，多栖为常态。

**五活动（列）**：建造／验收／运行／修改／举证。**与A-3生命周期五站的映射（F1）**：设计定型→建造；出厂验收＋试车→验收；投产→运行；运维改造→修改；**举证为跨站活动，无对应站**——此不整齐为有意登记，非疏漏（档案/台账的消费贯穿全生命周期）。
**六角色（行）**，各角色均有≥2个现存占位者（归纳自现有制品清单，非隐喻空推）：

| 角色 | 消费测试（缺位→何者停摆） | 现存占位者示例 |
|---|---|---|
| R1 运转件 | 运行停摆：数据流/执行/人工域裁量所经 | schema字段、engine、外挂内容物、模块结构与X边、主观调节册裁量位、交易手册（待建） |
| R2 语法件 | 建造/修改停摆：施工与改造动作的规程 | 骨架、归纳程序纪律、换装纪律、施工操作手册 |
| R3 判据件 | 验收停摆：合格与否无法判定 | G-1、判据链骨架、Y-1~Y-6、T3-24六问、S6检查单、§七换装检验协议 |
| R4 授权件 | 合法性停摆：语义/结构的正当性无出处 | 思想宪法、哲学准入×宪法对照表、翻译审计表、裁决记录之裁定面 |
| R5 档案件 | 举证停摆：回溯与争议无据 | 切片记录、撞墙清单、外审报告、摩擦定性件 |
| R6 台账件 | 治理循环停摆：开放项状态失踪 | 待修登记、治理缺口登记、升格候选册、自由度治理册之槽位登记面 |

**7-1 多栖登记法**：每制品登记主归宿一格＋兼职格清单（例：换装纪律＝R2主＋其§七任R3；自由度治理册＝R6主＋R2校准通道规程＋R1槽位取值指针；裁决落地文档＝R4裁定面＋R5档案面）。终-8"双栖件"由此消解为矩阵常态，B-3处置候选＝按本登记法逐件落位。

**7-2 空格三态**：矩阵空格判读＝已占／缺口候选／结构性空（无意义组合）三态，判读呈KD，不自动等于缺口（G-3同型）。已由矩阵机械重推出的缺口：运行×R3（运行期异常判据）＝B-5故障域；运行×R1人工域＝交易手册（T5待建），与既登记项重合，验证矩阵有效性。

**7-3 联动条款**：新制品建档时须登记任职格；S2按矩阵做完备性扫描（空格三态判读候选入裁决菜单）；S6检查单C-2映射对象由"结构块"扩为"结构块＋角色格"（规程侧机械更新随锚定案执行）。
