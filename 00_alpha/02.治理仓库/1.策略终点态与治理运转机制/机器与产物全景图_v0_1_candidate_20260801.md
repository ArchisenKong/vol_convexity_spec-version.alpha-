# 一、机器本身

## 1. 机器的三个基本构件

| 构件 | 角色 | 关键性质 |
|---|---|---|
| **会话** | 执行器 | 无状态、一次性、身份专用（构造/外审/复核/裁决台/归纳/任务包生成，六种身份互斥）。会话不携带记忆，用完即弃 |
| **受控文档** | 状态载体＝机器的全部内存 | 会话间传递状态的唯一介质。版本权威＝文件名（commit无语义）；cp-then-edit保证历史不可篡改 |
| **KD裁决** | 唯一动力轮 | 一切状态变更（候选→落档、open→闭合、判定翻转）只能由裁决驱动；会话只能产出呈报态 |

根本设计决定：执行器无状态，故**状态必须全部外化为文档**——文档族不是官僚制品，它是机器的内存与总线。

## 2. 主轴：单切片生产循环

```
批次对象选定 (Step1穿透过滤→Step2阶次判定→Step3哲学准入⊗宪法对照→Step4张力裁决) ──KD裁
      ↓
任务包生成会话 (裁决20：只装判据/约束/缺口指针，零技术路线；C4②审计表闸门开才可生成；确认即落档)
      ↓
切片构造会话 (模板三 A人造input→B一次性harness真跑→D三步断言；撞缺口四类互斥路由登记，不就地定义)
      ↓ 产出：一阶实体(schema+harness+真数) + 核验夹具 + 切片记录 + 撞墙清单
外审会话 (fresh context，盲列协议，三层攻击：复现/路径独立/变异注入；只审不裁)
      ↓
   ┌─通过─→ KD收口裁决
   └─缺陷回传─→ 修复会话(单一修复动作+变动面清单) → 增量复核会话(fresh context，重放标尺) → KD收口
      ↓
清点点①② (逐字对照全部登记容器的触发条件原文，命中呈KD裁闭/续挂) ＋ 台账写回
```

## 3. 外环：批次归纳循环

```
N根切片收口 → 清点点③ → 骨架/模块归纳会话(封闭输入清单，G-4结构不预定义，二阶规矩只从一阶反推)
→ 归纳外审(盲列) → KD定案 → 骨架/模块新版 → 下一批对象选定(强制复用骨架) → 回主轴
收敛判据＝连续N批(N=2)骨架零新增 → 阶段A可用态
```

## 4. 三条并行析出轨道

主轴每次消费一档/三档源文档时，内容按性质分流：

| 轨道 | 分流判据 | 去向 | 触发机制（含候选补丁） |
|---|---|---|---|
| 思想级 | 不变量/定义/优先序/裁量位 | 宪法（析出→KD逐条五选一） | 宪法已建成；再版联动闸（宪法再版→对照表先行再版→方可开下批Step3） |
| 规范级 | 操作规则/机制外壳/术语 | 升格候选登记册→KD裁析出再生→规范层汇编 | 〔候选补丁〕仿PB-1程序化差集比对绑清点点③；登记册强制时点入清点对照基准；术语册禁止误用栏入Step3工序/外审判据面 |
| 结构/取值/裁量自由度 | 三分判别（类一即裁/类二桩/类三槽位） | 自由度治理册槽位/信号、主观调节册 | schema随行指针强制携带（已闭环） |

## 5. 质量控制子系统（四层判据链的机器化位置）

- **L1实现层**：D段独立复算＋外审mutation＋#8桩-引擎对照——嵌在主轴每一圈。已建成，实证有区分力。
- **L2规格层**：翻译审计表C4②门（每个任务包生成前）＋三分判别＋哲学准入C1-C7——嵌在任务包生成与批次选定。已建大半。
- **L3结构层**：形态铁律三条已钉（证伪器非证实器／断言对象限账本非Greeks／反例路径注册制），操作化合法留白——将嵌在阶段B回测循环。
- **L4现实层**：留白——将嵌在paper/实盘循环。G-5/G-7占位。

## 6. 机器靠什么传动（会话间接口协议）

- **三类接口文本**：任务包（施工侧输入）／会话开启文本（身份＋授权源＋装载清单＋约束指针＋产出要求，不含判断）／落地文档（裁决全文载体）。
- **指针体系＝总线地址**：裁决N、宪-XX-NN、TPL/W/DOC/G/REG/EXP编号、文档ID＋行号复合键——一切引用走地址，不走复述。
- **两态机**：一切产出生而为呈报态（candidate），经KD收讫即落档（49-D全称化）——机器唯一的状态跃迁开关。
- **清点机制＝中断控制器**：事件入账点（外审收尾/裁决落地/批次开头/〔候选补丁〕A→B衔接开头）触发对全部登记容器的逐字扫描，防"登记后靠人记得"。

## 7. 机器消耗什么运转

三种稀缺资源：**KD裁决带宽**（最稀缺，故有"机械面自决申报、只escalate真判断位"纪律与治理开销观察行）；**fresh context**（身份隔离要求，不可复用）；**能力档**（外审侧不得低于施工侧）。防自耗装置＝三环空转戒律（工具制品只作副产物、凑批不即改、无第二消费方不设协作仪式）。

## 8. 可复用的机器 vs 本项目的料

**机器（域无关，可整体搬到下一个高不确定性构造项目）**：六种会话身份＋生产者不自审／裁决20任务包纪律／模板三A-B-D／三层外审＋盲列协议／缺陷回传-修复-增量复核环／清点机制／四层判据链框架／三轨析出（宪法-规范-自由度）／登记容器族形态（撞墙/待修/缺口/升格）／两态机＋指针体系＋cp-then-edit／G-4"结构不预定义"＋最小充分不外推。

**料（域相关）**：宪法41条内容、审计表内容、Greeks引擎、各切片、术语册8条。

# 二、产物及其结构

机器运转到阶段A终态时，吐出一个**分层文档-代码栈**，层间以单向权威链连接：

```
┌─ 顶层权威 ────────────────────────────────────────┐
│ 思想层宪法 v1.x（41条不变量；权威源＝生成裁决）        │
├─ 规范层 ──────────────────────────────────────────┤
│ 规范层汇编（术语册/修订通道/…篇章随升格生长）           │ ←单向上引宪法
├─ 核验层（桥＋常设检测区）──────────────────────────┤
│ 翻译审计表（源文行↔宪法条款三态映射＋模块对照区）        │
├─ 血缘源文（只读，永不改，只引不再生）──────────────────┤
│ T0/T1/T2/T3/GK/QQQAI原型 一档六＋八份                │
├─ 二阶结构层（从实体反推，持续可修订）──────────────────┤
│ 骨架 v2.x ＋ 模块划分 M1-M6 ＋ 合格判据链骨架          │
├─ 一阶实体层（机器的实质产出物）────────────────────────┤
│ 代码仓：每模块内若干根 {input_schema＋harness＋真数}    │
│ ＋ 各根切片记录（语义锚/合格判定/裁定登记/指纹）          │
├─ 自由度层 ─────────────────────────────────────────┤
│ 自由度治理册（槽位/占用者/参数挂接）＋主观调节册（裁量位） │
│ ＋ P_B注册记录（假设-反例）                            │
├─ 治理台账层（机器运行日志，本身也是交付物）─────────────┤
│ 执行期裁决记录＋落地文档族／待修登记／治理缺口登记／        │
│ 升格候选登记册／各撞墙清单                              │
├─ 操作纪律层（机器的说明书，即"机器"的成文体）───────────┤
│ 操作手册／任务6模板三／三分判别受控文本／归纳程序纪律       │
└─ 经验层（非权威，pull-based）：EXP/QT笔记 ─────────────┘
```

**交付给阶段B的是一张"已跑通的图"**：不是设计文档，是实体集（有真实输出、经三层外审）＋从实体反推的规矩＋每个未决项的显式登记（缺口≠欠账，G-3口径）。阶段B拿到的不只是代码，是**代码＋它的全部血缘＋每条规则的证据链＋每个自由度的治理挂接点**——这是"同源同核"和"Greeks自建"两条生死线能在阶段B守住的前提：任何阈值判据都能沿指针回溯到宪法条款和一阶实证。

## 两个维度的关系

机器与产物不是分离的：**操作纪律层＋治理台账层就是机器自身的成文体**——机器在运转中把自己写成文档（手册凑批、判据面成文、代写边界八条成文）。阶段A结束时交付的既是策略工程的"图"，也是这部机器本身的可复用副本。
