## 1. B段计算路线裁定

选定路线：**离散算术路线**（任务包§3 B段"允许的最简路线"）。

理由：
- Q4 判据只要求"喂路径集+持仓，出各路径P/L与worst值"，未要求对持仓做连续重估。
- 期权到期payoff取内在价值（`max(S_T-K,0)`，纯算术：减法+比较+乘法），不需要定价模型；对冲比例取阈值声明规则（见§3），不需要Greeks/BS计算。
- 全程不撞 TPL1-T76-01（品种感知自算Greeks/定价引擎缺口）——本根未选定价桩路线，无该依赖。

## 2. 持仓构造（人造声明）

单一持仓：短 1 张 call option（做市商/对冲方视角），并按阈值规则动态对冲标的。

| 字段 | 值 | 说明 |
|---|---|---|
| instrument | short_call | 期权方向（空头认购） |
| strike (K) | 100 | 执行价（整数，保证bit-exact可判性） |
| multiplier (M) | 100 | 每张合约对应股数 |
| quantity | -1 | 合约数（负＝空头1张） |
| premium_per_share | 3 | 期初每股收取权利金（整数） |
| premium_total | 300 | = premium_per_share × multiplier |

**对冲规则（占位声明·桩，裁决16降格标注；对冲政策＝上游输入，非TC-33实体算法要件；权威定义缺失已登记TPL1-TC33-01）**：

```
h(t) = 1  若 S(t) >= K
h(t) = 0  若 S(t) <  K
```

区间 `[t, t+1]` 内持有 `h(t) × M` 股标的对冲仓位（用 t 时刻已知价格决策，无前视）。此阈值规则为本根占位输入源（桩）：真实供给方为待建的对冲政策对象（TPL1-TC33-01，open）；未来重估路线下可替换为模型Delta调仓序列，TC-33实体本体（逐路径聚合＋worst确界）不随之改写（裁决16）。不引入外部定价依赖。

## 3. 路径P/L计算公式（逐路径适用；其中hedge仓位h(t)与"期初/到期两点估值"约定＝上游输入之占位形态，裁决16；聚合结构Σ与worst确界为实体算法要件）

对路径 `S = [S(0), S(1), ..., S(T)]`（T=4，5个价格点，4个区间）：

```
hedge_pnl(path) = Σ_{t=0}^{T-1} h(t) × M × (S(t+1) - S(t))
expiry_payoff(path) = max(S(T) - K, 0) × M
path_pnl(path) = hedge_pnl(path) + premium_total - expiry_payoff(path)
```

worst = min(path_pnl(path) for path in 路径集)（集合上确界/最差取值）。

全部变量为整数，全部运算为 `+ - × max 比较`，无浮点舍入风险 → 适用裁决13子口径(a)：离散/精确有理计算，容差＝0（bit-exact）。

## 4. 路径集设计（人造声明，覆盖非平凡worst判定）

5条路径，K=100：

| path_id | 设计意图 | 价格序列 |
|---|---|---|
| P1 | 高频穿越strike（choppy），检验对冲反复翻转成本 | [100,102,98,103,99] |
| P2 | 单调上行至110，全程ITM持续对冲 | [100,101,103,106,110] |
| P3 | **同终点110（对照P2）**，先深跌OTM后末端急拉 | [100,95,90,98,110] |
| P4 | 压力路径：OTM盘整后末端跳空至160，末段未对冲缺口 | [100,95,92,95,160] |
| P5 | 基线：全程OTM无穿越 | [99,97,94,96,93] |

P2/P3 同起点(100)同终点(110)、路径形状不同 → 检验"相同终点不代表损益相同"（TC§7.6语义直接对应）。
P4 为细则(c)压力路径：期末跳空穿越K且跳空前一区间对冲已关闭（h(3)=0），造成末段完全未对冲的大幅不利变动，预期为worst候选，且量级远超权利金300 → 验证"权利金不是动态对冲者完整风险上限"。
