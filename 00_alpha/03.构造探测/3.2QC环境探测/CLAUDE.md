# 工作目录行为约束

本目录用于 QuantConnect 环境探测任务。执行前必须先读 `QC环境探测_任务书_v1_0_20260814.md`。

## 不可违反

1. **缺参数即停。** 任务书未显式给出的任何值——账户凭据、路径、日期、标的、参数——一律停下来问。不猜、不填默认值、不用占位值继续。
2. **不购买数据。** 禁止 `lean data download`、`--data-purchase-limit`，禁止任何可能触发计费的操作。
3. **不寻找替代数据源。** 禁止 yfinance、爬虫、第三方行情 API。缺数据即停并报告。
4. **不绕过阻断点。** 撞到 403、权限拒绝、配额上限，记录后停在该步报告，不自行改走其他路径。
5. **不写策略逻辑。** 本任务的算法只用于探测通道。不得有交易逻辑，不得输出收益、夏普、回撤类指标。
6. **凭据不落盘、不转述。** QC user id 与 API token 由执行人在终端交互式输入。禁止写入任何文件、禁止在对话中重复、禁止出现在日志里。若日志中意外出现凭据，立即删除该日志并告知执行人作废重生成。
7. **失败即产出。** 报错、被拒、受限都是本任务要采集的东西。不要为了"让它跑通"而改变任务书规定的动作。

## 记录纪律

- 每条命令的完整命令行、退出码、stdout、stderr 全量落盘，不做摘要省略。
- 每步执行完立即写记录表，不攒到最后。
- 顺利的步骤也要显式记录「F0，无摩擦」。
- 现象与原因分开写。记录表只写发生了什么，推测原因单独成节。

## 报告纪律

- 只呈报现象与三态结果。
- 不给出「环境可用/不可用」的总体结论。
- 不给出后续方案建议或路径推荐。

总体判定与后续决策由执行人作出。
