## 条目

### QT-001 · 容差分派的成分级（非族级）应用

| 字段 | 内容 |
|---|---|
| 日期/来源 | 20260726，T-33切片构造＋外审复核（外审报告§1第二层第10项、P-4）；KD裁定收录＝裁决34-F2；容差实测值入档＝裁决34-F1 |
| 类别 | NUM |
| 适用范围 | 量化工程通用 |
| 触发情境 | T-33五族人造路径中，族Q价格生成含超越函数sin（C3分派判据命中子口径(b)相对diff≤1e-12），但族Q的crossing_count（穿越计数）仍按子口径(a) bit-exact（diff=0）比对，未因所在计算路径含超越函数而放宽 |
| 教训/问题 | 容差子口径的分派单位若取"族"或"计算路径"（上下文级），会把离散派生量错误地纳入放宽口径——整数计数结果在两条独立实现路径上若不逐位相等，即为实现分歧，1e-12容差会掩盖它 |
| 根因 | C3分派判据（超越函数在场性）的作用对象是**被比对的数值本身**：价格序列（浮点，超越函数直接产物）与穿越计数（整数，价格序列的离散函数）是不同成分。计数不引入额外舍入，比对对象是整数本身 |
| 可迁移原则 | 逐成分分派：对每个进入数值比对的量单独问"该量本身的取值过程是否引入连续解析舍入"，而非问"它所在的计算路径是否含超越函数"。同一根内允许(a)(b)两口径并存于同一族 |
| 技术内容 | T-33实测入档值（裁决34-F1）：族P/O/Z/N（整数/Fraction精确有理）全项diff=0；族Q逐点价格相对diff=0.000e+00、rv_proxy相对diff=1.735e-16（≤1e-12上限，子口径b）、crossing_count diff=0（bit-exact不放宽）。锚定值情境依赖纪律同步确认：各族本根首次实测，未跨复合度搬运（C3命题，X4实证链） |
| 项目实例指针 | T-33 input_schema §5（crossing_count恒按bit-exact之注记）；切片记录§3-6；外审报告§1第二层第10项；裁决13/19（两子口径设立与锚定值修订） |
| 适用边界/反例 | (a) 离散量若定义本身依赖浮点比较（如"价格>阈值"计数且阈值为浮点计算产物），边界点归属可能受上游舍入影响，此时计数的bit-exact比对可能因合法舍入差异失败——须先核对边界点是否落在舍入敏感区（T-33族Q边界点103.0/97.0为精确可表示值，未触发）；(b) 反例待寻 |
| 状态 | **假设待验证**（单根实证；跨根第二例待后续切片） |
| 关联条目 | EXP-003（不同族：本条属数值口径，EXP-003属验证方法论） |

| 教训/问题 | 缩放因子是纯表示层约定，但混用＝静默错：同账本内per 1.0σ与per 1%并存差100倍，数值均"合理"，断言测试不FAIL，错误至消费端才显形且难归因——"系统正常运行、数值全错"形态。事前唯一便宜拦截点＝口径契约（JP-1入1级之依据） |
| 可迁移原则 | 全链单一raw口径＋缩放只在最终展示层做一次＋换算责任在展示端；任何"每单位变动"读数先问单位（1.0还是1%还是1bp），单位差即10²/10⁴量级差 |

### QT-003 · 口语高阶导术语的工程解压：Speed触发量与四阶导不变量分立

| 字段 | 内容 |
|---|---|
| 日期/来源 | 20260803，续3 FW-03-甲外审D-10→裁决60-A1（KD作者语义权裁定"两量并出"）→丙类修复落写→增量复核E-②零漂移确认；KD指示收录（"整理到期权波动率工程笔记……比较像后续的操作指南"）；收录裁定＝裁决61 |
| 类别 | VOL |
| 适用范围 | 项目全链（roll触发判据族：FW-03-甲/乙、GL-05同域）＋期权工程通用 |
| 触发情境 | 源文（亿口气回复行11–12）一句话内"二阶导"承载两个数学对象：等式句"gamma最大的时候也就是二阶导为0"与不变量句"保持整个头寸的gamma的二阶导数一直为正"。首轮实现取∂²Γ/∂S²单一读法并以"字面松弛"消解等式句，外审量化揭示两读法产出**不同状态量**（过零4次 vs 2次、触发时点相差一个价格区间） |
| 教训/问题 | 交易口语的高阶导术语（"二阶导""Gamma的Gamma"）常按**功能**而非**阶数**指称：追踪"Γ在涨还是过峰了"时说的是Γ的斜率（Speed＝∂Γ/∂S＝∂³V/∂S³）；主张"做多四阶矩/凸性的凸性"时说的是Γ的曲率（∂²Γ/∂S²＝∂⁴V/∂S⁴）。工程化若强选单一读法，必使源文另半句失真，且属静默取读法（就地定义违纪） |
| 根因 | 微积分事实：Γ(S)为单峰山形——山顶处**斜率为零、曲率为负**（极大值二阶条件），故"Γ最大⇔∂²Γ/∂S²=0"数学上不可能成立；"Γ最大⇔Speed=0"为恒等式。两句各自精确对应一个对象，压缩表达≠语义缺陷，但解压是工程化前置义务 |
| 可迁移原则 | ①凡口语化高阶导表述入工程，先问"该词在此句的**功能**（触发检测/不变量维护/风险度量）"再定数学对象，功能不同即解压为多对象分别实现，禁按字面阶数强选其一；②触发量与不变量分立是通用形态：触发（过零检测）天然per-leg、沿路径；不变量（恒正）天然组合级、靠动作维持——静态单腿情景下不变量被违反是**设计性质**非缺陷；③符号序列输出对参数漂移免疫（峰/拐点位置随σ/T/r移动，但"峰在strike附近、峰处曲率为负"的定性结构对vanilla稳定），操作指南应锚符号事件而非绝对价格位 |
| 技术内容 | FW-03-甲实测（K=100, r=0.04, q=0, σ=0.25, S:135→72→135, 43步）：speed过零2项（t13→14即S 96→93＝"Γ峰值已过"、t28→29回摆），解析求根S*=95.10，与源文"已变ATM"吻合；curvature过零4项（S≈109.5/81处两对拐点）；curvature恒正核验False（18步为负）＝静态不roll情景之必然，恒正靠roll重置维持（组合级）。数值方法与量级界：speed界0.002、curvature界0.01（各按截断量级独立标定，实测边际均≈12×），取值挂TPL3-FW03A-01族条目候Phase B校准 |
| 操作指南读法（Phase B/实盘视角，非构造依据） | roll触发家族已并立多候选：Speed过零（Γ峰＝腿变ATM，货币化幅度大）／curvature过零（拐点，更早、腿仍虚）／GL-05之Γ回落建仓水平（峰后更晚）。乙层（roll编排）择一或组合属KD后批裁量；甲层只报两通道状态。触发时点差异直接改变货币化节奏与保护重置成本，Phase B择优须与品种路由需求（美式无闭式→差分通用 vs 欧式闭式精确）同批裁 |
| 项目实例指针 | 裁决60-A1（权威裁定）；FW-03-甲 input_schema §2（双锚定权威落写）；撞墙清单_FW-03-甲 v1.1模板二D-10结案文本；外审报告_续3 §5 D-10量化表；增量复核报告§5.3恒等式验证；宪-CV-06（触发半句＋四阶矩半句）；杠铃行887 |
| 适用边界/反例 | (a)本条**非构造权威**：构造与审计以裁决60-A1与schema §2为准，本条仅读法/操作辅助（QT-002同型定位）；(b)多腿组合Γ地形非单峰时，"峰/拐点"局部结构复杂化，符号事件解读须先做组合级聚合（本根per-lot，组合级归下游）；(c)"沿不利方向取号"绑定头寸性质（put保护腿＝下行），反向头寸须重定adverse_direction，禁默认搬运 |
| 状态 | 定案约定（操作指南辅助；触发候选择优＝Phase B开放项） |
| 关联条目 | QT-002（同为"读法辅助、权威载体在别处"定位）；EXP-系列若后续登记"一词双职"治理层教训则互挂指针 |
