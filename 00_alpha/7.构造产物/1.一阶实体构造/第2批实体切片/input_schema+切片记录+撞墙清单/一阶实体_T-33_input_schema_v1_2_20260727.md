## 4. 短端义务区与路径参数（人造声明，见 entity/input_params.json）

- 短端义务区（短端body边界，近ATM近似）：`K_low=97`，`K_high=103`，`S0=100`。
- 族P（分段线性三角波，整数步长）：leg_step=2，leg_length_steps=3，num_full_cycles=2，单周期12步（up→down→down→up各3步），总25个价格点（t=0..24）。全程整数/精确有理运算，**无超越函数**——C3分派判据命中容差子口径(a) bit-exact（裁决13）。
- 族Q（正弦振荡）：S(t)=S0+A·sin(2πt/period)，A=6，period=12，num_steps=24，共25个价格点。生成过程**含超越函数sin**——C3分派判据命中容差子口径(b) 相对diff≤1e-12（裁决13设立、裁决19修订锚定值）。
- **EXP-002强化表述反例族**（裁决31执行义务3，KD裁定随行20260726；本对象判据面为"低IV＋震荡"复合布尔，采纳该建议为两个布尔子判据分别构造双向反例，防止在人造input上恒真/恒假逃逸——采纳情况见§5末段）：
  - 族O（低IV但不震荡）：三角波，S0=150（远离短端义务区[97,103]），leg_step=2，leg_length_steps=3，num_full_cycles=2。设计意图：小振幅、全程不触及zone。
  - 族Z（震荡但非低IV）：三角波，S0=100，leg_step=20，leg_length_steps=1，num_full_cycles=3。设计意图：大振幅、高频穿越zone。
  - 族N（两者皆非）：单调趋势，S0=100，step_size=15，num_steps=4。设计意图：单次大步幅穿越、无回归震荡。
  - 族O/Z/N与族P同为整数/精确有理运算，无超越函数，均命中容差子口径(a) bit-exact。
- **族B（边界触碰折返，v1.1修复动作(c)新增，裁决34-B2；对应外审E2逃逸修复）**：从S0=100出发依次恰好触达短端义务区边界[K_high=103, K_low=97]交替目标点（num_bounces=6：103→97→103→97→103→97），每次到达边界值本身、从不越过。全程Fraction精确整数运算，无超越函数，命中容差子口径(a) bit-exact，本族首次实测锚定值（未跨复合度搬运）。**设计动机**：既有族P/O/Z/N全程步长为偶数、义务区边界为奇数(97/103)，路径从不恰好落于边界；族Q虽有若干点数值上恰好等于边界值，但均处于"继续同向前进穿越"语境，边界读法（`>`严格排他 vs `>=`含边界）之差异不改变总crossing_count（详见外审报告E2逃逸定性：**"crossing_count对该读法结构性不敏感"**）。族B改为"触碰即掉头"语境，使两读法在此产生真实数值分歧（当前候选读法下crossing_count=0；若K_high判据由`>`突变为`>=`，crossing_count变为6），使该项操作化候选之分歧成为可被现有bit-exact比对捕获的结构性区分——修复记录附独立验证（隔离副本自检，非本文档执行内容）。
- 六族参数（振幅、周期、义务区宽度、触碰目标序列）均为本根人造声明，构造自由度（数据/机制刀口：路径生成参数值本身为构造自由度数据，不进入三分判别；穿越计数与RV代理度量之"计算方式/公式结构"属机制成分，见§6，**v1.1改判为类三，非v1.0原类一定案**）。

## 5. 派生度量与分类候选（说明性，非冻结判据）

- **crossing_count**：路径相邻点相对短端义务区状态（in / out_above / out_below）发生变化的次数——离散计数，恒按bit-exact（diff=0）比对，不因族Q价格生成含超越函数而放宽（计数是价格序列的离散函数，比对对象是整数本身，不引入额外舍入；C3容差分派判据作用于"数值本身"，此处对象为价格序列，计数结果之比对独立处理，见verify/assert_check.py注记）。
- **rv_proxy**：均步幅 / S0，作为"低IV"定义特征之说明性代理度量。族P为Fraction精确值，族Q为浮点值（继承路径生成的超越函数依赖）。
- **分类候选阈值**（`entity/input_params.json` § classification_candidates，均标注`parameter_slot_candidate`）：
  - `low_iv_rv_proxy_threshold_candidate = 0.05`：候选，rv_proxy ≤ 该值视为"低IV"定义特征之说明性满足。
  - `oscillation_crossing_count_threshold_candidate = 3`：候选，crossing_count ≥ 该值视为"反复穿越"定义特征之说明性满足。
  - 两候选值均为Phase A说明性核验用途，**非冻结生产判据**，边界受§3引用条款直接约束，不外推为生产字段或执行规则。
