## §2 禁作面（违反即停）

1. **不产出**「成功／失败」二值结论，**不作**「环境可用／不可用」总体判定（85-9 反面条款）。
2. **不产出**任何 L3 判据、L3 实体、合格判定；五量之取值／阈值／分桶法／路径生成器规格一律不写。
3. **破坏性动作全禁**（A'-14）：`lean cloud push`、`object-store delete`、`files/delete` 于全工作树命中数 ==0。**探测期遗留物一律不清理、不删除、不覆盖**（A'-12）。
4. **不改 engine 源码、不改 GL-06 schema**；两者均为逐字复用件。
5. **不填未给定数值**；不预设结果、不为跑通而改目标。
6. 撞到缺口即**登记并继续**，不就地定义、不静默绕过；缺口**不自立撞墙条目**，走「呈 KD 事项登记」栏（85-8）。
7. 口径漂移防线：**本任务不是「把环境跑通」**，是采集摩擦。跑不通同样是有效产出。

## §4 工作树与装载

```
p2prime_workdir/
├─ entity/    人造，零真实数值：engine 件、GL-06 四件、纯人造 harness
├─ verify/    断言脚本、断言日志、X-1 比对件、独立复算件
└─ probe/     唯一允许触碰外部数据之子树；QC 接口面代码全部落此（A'-6）
```

- `lean init` 样本数据纳入 `probe/` 三分射程，以**目录级**登记（文件清单＋清单件 SHA256＋总字节数），非逐件入 manifest（A'-7）。
- 云端项目**仅承载 `entity/` 面**；`probe/` 面一律不上云（A'-9）。**即停条件**：若出现「必须上云方能推进」之 probe 内容，停并呈 KD，不得就地扩射程。
- 置 `AGENTS.md`，含乙-6 声明句「打包/外发落位须 KD/KY 显式裁定」＋本件 §2 禁作面三条摘要。
- 载入后即跑首次核证：A5'（engine 指纹）／A6'（零写入）／A9'（GL-06 四件指纹）。

## §5 执行序

1. **基线快照**（只读，零写入零删除）：云端 `files.get_all()` 清单、`object-store list`、`research/read` 节点状态 → 落 `probe/`。遗留物由此隔离，不清理。
2. **α 探查**（规格件 §3.1 六面）：α-1 三候选注入通道逐条实测，记 exit code 与错误原文；α-2～α-5 逐面记录；**α-6 在回测运行时与 research 内核各跑一次**，GL-06 自带 15 期人造账本 input 实跑，与本地 `harness_output.json` 逐字节比对，两位分行记录。
3. **X-1 素材**（规格件 §3.2）：**回测运行时与 research 内核并跑**，fixture＝`X1_SYNTH_ES_001`（不新造），引擎＝v1.3（v1.2 不并跑）。两位各采环境指纹四项（Python／platform／libc／libm 摘要），逐位输出以 `repr` ＋ IEEE754 hex 双表达，经 E1-07 矩阵内通道回传。**两位结果分列，不合并、不取其一。**
4. **每步后**：跑 `verify/probe_assert.py`（A1'–A12'）；填记录表；载荷**先落原件**再解析、文件名带序号或时间戳（乙-5）。
5. **封包**：交付件任何修改后复跑断言，**末次零 FAIL** 且全部 `INDETERMINATE` 项已双值留痕，方可封包（丙-3）。
6. **交付** → P3' session。

## §6 断言执行口径

- A1'–A12' 依规格件 §5 执行，逐项入日志。
- **`INDETERMINATE` 态**：仅限 A5' 之 CRLF 双值并列一项；须同时记录云端侧值与本地侧值，缺一即判 FAIL。其余断言无此态。
- 断言日志（逐项 PASS／FAIL／INDETERMINATE）＝交付件之一。
