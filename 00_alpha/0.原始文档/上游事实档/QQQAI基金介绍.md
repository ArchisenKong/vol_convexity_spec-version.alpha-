# QQQAI基金在做什么？第一部分期权降本循环。
以apple公司股票期权市场为例，股票现价格240.05，卖出240的看跌期权会有哪些可能？执行价240，价格3.3的看跌期权到期后有两种可能，若apple股价大于240，那么你除了现金将一无所获，期权没有交割的情况称为轮空，每张合约获得现金330美元。反之若apple股价小于240美元，那么我们将获得打折价股票成本价为240-3.3=236.7，折扣率约为1.3%，若轮空获取了330美元记录累积现金收入，把所有收入都放进储蓄罐，若获得的是打折股票，我们同样记录折扣后的价格，股票的数量和我们实际花的钱都要记录在案。    

那么问题来了，如果三周轮空了，两次获得折扣股票一次，整个账户持有股票的真实成本应该是多少？我们有了成本为236.7美元的100股apple股票以及两次330美元的现金收入，可以摊薄入股价，则账户实际的持股成本为236.7-3.3-3.3=230.1，此计算出的成本称为摊薄后成本，我们不禁要问，为什么每轮都能不断降低成本？好处必然有一个源头琢磨一下明白，无论期权轮空与否，期权买方总要付费，卖方的收入总是确定性收入，买方每次都支付，自然卖方每次都受益，就不要谦虚质疑了。    

如果不轮空总是吃到股票如何降本呢？我们不可能无限吃进股票，毕竟没有人的钱是无限多的，当股票已经偏多时怎么办？此时我们可以反向卖出看涨期权，同样有两种未来的可能，若apple股价每股小于240亿，那么同样轮空获得350美元现金收入记录在案，同样存入储蓄罐，若apple股价每股大于240，按照合约定义，我们需要以240的价格卖出股票，且收入350美元的权利金，相当于240+3.5=243.5卖出，这个价格称为等效出货价。    

我们只需要确保等效出货价要大于等于，我们赶紧翻翻我们目前为止的账本，我们上一轮的摊薄后成本，等效出货价减去摊薄后成本等于进出价差，相当于一次进货与出货，这和所有其他生意没任何不同，低买高卖一进一出获取的价差收入，因为价差收入是已经出货了股票的，所以是价差收入是现金收入，我们加上所有的累计的轮空收入的总和，包括了轮空的看涨和看跌，就是我们之前所有储蓄罐里存的钱，加起来就等于我们的总现金收入，总现金收入与我们之前所有之净没有被卖出的股票的折扣后价格综合计算，得出的就是新一轮的摊薄后价格，这个是计算的式子，不要被吓到。这个是计算是我们QQQAI的基金经理的工作，累计的现金收入恒为正，持续的降本，我们耐心累积，终有一天成本会变成0，这就是我们的目标了。    

每周一轮，每轮降低成本，每股3.3~3.5美元，相当于apple股票的成本有多大意义？我们来看apple公司的财报，季度的EPS平均为1.7美元一股，相当于周期权费收入的一半。按一季度12个交易周算，把期权费收入当做公司盈利来看，就好比公司每季度多盈利了24次，再看三五十倍的估值就没那么高不可攀了。聪明的你一定意识到了一个问题，既然每一轮无论是否轮空，最后的总摊薄成本都会降低，是不是轮空的越快越好，你是对的。

告诉大家一个好消息，现在美股指数ETF有了每日到期期权，例如包含了几乎所有AI概念股的ETF、纳斯达克ETF基金QQQ，可以看到期权市场到期日覆盖每一个交易日。万事大吉了吗？肯定没有那么容易。虽然我们可以通过轮空收益加上价差收益，不断加持已经打折的股价，使得摊薄成本越来越低，但这需要时间，股市突然短时间内连续暴跌怎么办？对应的虽然卖看跌，在股市上涨的时候不断轮空，能收集到权利金，但收益有限，会不会错过资产本身的大涨？结果捡起了芝麻，丢了西瓜，这确实大有可能，这些确实值得深入思考。面对无法优哉游哉刷成本的暴涨暴跌去吧。请关注第二部分期权机构化形错配。


 # QQQAI基金在做什么？第二部分期权结构化期限错配。
 
这是一个简单的struggle的图示，让我们忘掉所有模型一个straddle的价格代表了什么？标普指数6000点，为期一周的straddle卖100个点，我们到底在交易什么？价值100的一周straddle，买方认为周波动超过100点，对应卖方认为一周的波动不超过100点，同时一个月价格200，买方认为月波动超过200点，对应卖方认为一个月的波动不超过200点，那么问题来了，如果期权的价格是连续对冲的累积，一个月有4周，为什么价格只差一倍，让我们回到straddle的原始含义，这个波动预期的估值必然是合理估计，否则市场不会交投。与时长比例不相符的原因，在图上一看便知，将straddle价格看成k线的实体部分，去掉上下引线部分的高度，想想straddle可不就是在对赌k线无影线部分实体的有多长吗？4根周k线合并成月k。但凡行情不是单方向，必然有月k的高度小于4倍周k高度，因为来回重叠的部分被合并吸纳掉了，不妨自己想象一下，即当一个月内但凡有反复来回，在1月straddle就应当小于共4周straddle的总和，这个显而易见的现象能为我们带来什么？    

我们来简单想一想这个结论能推论出什么？对应同样体量的底层资产的期权，越长期其平均每日开销越低，但他们承担的义务和保护能力的资产量是完全相同的。这意味着期权不同到期日之间的期限错配是有利可图的，即卖短期期权进行降本循环加买入长期期权形成结构是可行的。回忆一下只有期权降本循环的缺陷，暴跌时候的保护垫由日常权利金收入累积而来，很有限，暴涨时只有权利金收入，错过高收益。暴跌时买入平均日开销小于日期权收入一小部分，且张数大于两倍的看跌期权，暴涨时买入平均日开销小于日期权收入一小部分，且张数相当于一倍满仓需要的底层资产量的看涨期权。    

暴跌时候的应对措施能让我们跌时不受伤，暴涨的应对方法能让我们涨时不踏空，行情连续暴跌时，持有的长期看跌期权的张数大于等于（已经吃货的量加上义务仓假设全部吃进的量）再乘以2，且日常满足长期看跌期权的theta开销远远小于卖短期期权的日常权利金收入。跨期期限错配使得整个结构变得可能。

我们用25年1月底到3月初的行情举例，绿线为纳斯达克100指数，蓝线为基金回报率，QQQAI基金底层标的指数下跌接近8%时，基金几乎无亏损，暴跌发生时完美渡劫。行情连续暴涨时，持有的长期看涨期权的张数大于等于（不踏空需要的资产总量减去已经吃货的量），且日常满足长期看涨期权的theta开销远远小于卖短期期权的日常权利金收入。跨期期限错配使得整个结构变得可能。24年9月20-11月初的上涨行情，绿线为纳斯达克100指数，蓝线为基金回报率，底层标的指数上涨接近6%时，收益于10%，没有踏空。使用期限错配渡劫暴跌和防止踏空的代价是原本满值的日期权的高额的theta循环收入，近半用于支付了长期期权的开支，降本速度打了对折，好在基础收益够高是非常值得的交换。
