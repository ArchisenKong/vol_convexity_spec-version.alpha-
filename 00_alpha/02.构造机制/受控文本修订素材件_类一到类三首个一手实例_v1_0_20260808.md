## 二 · 一阶实例

### 2.1 实例标识

- **对象**：四1（T3-15，收益来源四类·归因schema维度）之计算成分 **C4 ＝ 4.1 内部线性/凸性子分解之一阶基准坐标**。
- **原判别（构造侧呈报态，20260806）**：**类三**（受控文本§4）。所载依据原文：「三候选（`pre_t_pre_S`／`post_t_pre_S`／中点）与全部权威文本相容、逻辑均自洽，**无文本可排除**」。
- **登记去向**：TPL3-T315-01，挂 A→B 衔接清单，形态同 TPL3-T24-01。
- **订正裁定**：裁决75-1（20260808）——**结构面逻辑排除定案／数值面维持类三**。

### 2.2 错分之判定路径

受控文本§4 之类三判别测试原文：

> 判别测试：问"有无任何已有文本**或逻辑**能排除某候选？"全否→类三。

构造侧之依据陈述为「无**文本**可排除」，**未覆盖测试所含之「或逻辑」半**。裁决台复核发现逻辑排除在场，故「全否」不成立，类三定性于结构面不成立。

**排除论证**：`diag_S_convex` 由 schema §5 明文承载「功能面之收益来源主张」。中点基准下，二阶项被吸收入 `diag_S_linear`，残差落至三阶——`diag_S_convex` 不再度量凸性，该功能主张**失去指称对象**。故中点候选与 schema 自身之功能声明矛盾，可排除。

### 2.3 一手实证（裁决台实算，长端＋短端汇总）

| 基准坐标 | path A `diag_S_linear` | path A `diag_S_convex` | path B `diag_S_convex` | 相消比 |
|---|---|---|---|---|
| `pre_t_pre_S` | +14581.03 | −14383.06 | −18041.82 | 74× / 64× |
| `post_t_pre_S`（在跑） | +16463.65 | −16265.69 | −18911.59 | 83× / 67× |
| `midpoint_S`（**已排除**） | +147.75 | **+50.22** | **−136.40** | 0.7× / 1.5× |

（`C41_S_channel` ＝ Σ`ch_S` ＝ 197.96／287.60，三候选下不变；步长 ΔS ＝ −40／+60／−15，约 8–12% 之跳）

**path A 上符号翻转、量级降约 300 倍。** 三候选并非同一量之数值校准——中点候选改变的是**被度量对象本身**。把它留在类三候选集内，等于要求 Phase B 以回测数据在「凸性收益是 −16265 还是 +50」之间做选择；该选择是**定义性的、可由逻辑演绎作出**，而非经验性的。这正是该错分格所述后果之字面形态。

### 3.1 §5 错分定性表「类一→类三」行

**建议**：证据列由二手引述改挂本一手实例，并撤去文头之显式例外标注。

拟写形态（仅示证据列）：

### 3.2 §4 类三判别测试之执行提示（**新增候选，非必须**）

**观察**：本例之错分机制不在规则本身，而在**执行时只做了测试的一半**——依据陈述写「无文本可排除」，而测试要求「无文本**或逻辑**可排除」。

**建议（呈KD，不预裁）**：§4 判别测试项下加一句执行提示——**类三之否定结论须分列「文本面查过什么」与「逻辑面查过什么」两栏**，缺一栏即测试未完成。形态援引 §2 类一之既有「否定结论义务」（判"裁不了"时须记录查过哪些文本、为何裁不了；实例＝T-24切片记录行99-100）——即把类一已有的否定结论义务**对称地扩到类三**。

**反面考量（如实并列）**：受控文本之拒收纪律为「零实例规则不成文」。本条若成文，其实例支撑仅本例一条，且属**规则执行面之提示**而非新规则。是否达到成文门槛，归KD与受控文本外审通道判定；本件不预裁。

### 3.3 「成分内再拆分」条之实例增补

§2 现载「同一成分可结构类一、数值类三。实例＝裁决18 R3」。本例为该条之**第二个一阶实例**，且形态略异（R3 为结构由权威文本裁出，本例为结构由**逻辑排除**裁出）。建议并列登记，使该条覆盖「文本裁出结构」与「逻辑排除结构」两形态。
