### EXP-002 · 人造 input 的边界态零覆盖削弱验证力

| 字段 | 内容 |
|---|---|
| 日期/来源 | 观察＝T3-17 外审报告 v1.0（20260718）观察项 O3；裁决24-A7 O3 裁定"记入工程构造经验笔记候选（KY自选收录）……不登记"（20260721）；**录入＝20260725（KD确认收录，补早裁未录之欠账）** |
| 类别 | VER |
| 触发情境 | T3-17 切片的人造 input（两翼各24期）存在两处边界态零覆盖：(a)"首期即 below_floor"边界零覆盖；(b) band 三态之 `above` 分支在两翼24期中零出现 |
| 教训/问题 | 两处零覆盖各造成一处验证力损失——(a) 变异 M6（复算 accumulate 初值 0→1）因该边界未被触及而"语义中性存活"，无法区分真中性与被 input 掩盖，该变异被迫排除出击落分母；(b) 附加断言③的 above 分支枚举检查在本根为**空转**，断言在场但从未执行 |
| 根因 | 人造 input 的构造自由度不受判据约束——判据只要求"覆盖 Q4 判据所需最小输入"，而最小输入不等于状态空间边界覆盖。执行方按"够用即可"构造，自然落在典型态，边界态与稀有分支系统性缺席 |
| 可迁移原则 | **断言与变异注入的检出力上界由 input 的状态覆盖决定，不由断言数量决定。**写了断言不等于断言被执行；变异存活不等于变异无害——须先排除"input 未触及该路径"这一解释，再谈中性。构造人造 input 时，除判据最小覆盖外，宜显式列举被测对象的状态分支与边界，逐项标记覆盖／如实标记未覆盖 |
| 项目实例指针 | T3-17 外审报告 v1.0（O3 条＋M6 变异行）；裁决24-A7 O3（**不登记**撞墙清单、仅入 EXP，理由＝人造 input 构造自由度内、非判据不符） |
| 适用边界/反例 | (a) **本条不构成对 input 构造的新判据**——裁决24-A7 明写"不登记"，即不入撞墙清单、不改任务包判据面；仅为后续根构造的边界意识；(b) 全边界覆盖与"人造 input 最小充分"存在张力，过度扩张 input 推高构造成本并稀释 Q4 判据聚焦，平衡点未定、待多根实测；(c) 若某边界态在被测对象语义上不可达，标记不可达即合规，不必造出 |
| 状态 | **假设待验证**。单根观察（T3-17）；第二批四根可提供复验样本 |
| 关联条目 | EXP-001（不同族）。**路由判定留痕**：本条内容含 below_floor／band 三态等波动率域术语，但教训本体属验证方法（input 覆盖与检出力关系），依路由规则第一行归 EXP，不拆 QT 条目；域内术语仅作实例指针 |

### EXP-003 · 覆盖率断言≠判别力（双向反例的虚假安全感）

| 字段 | 内容 |
|---|---|
| 日期/来源 | 20260726，T-33外审会话（claude-opus-5，fresh context）。一手观察＝外审变异实证；KD裁定收录＝裁决34-F2 |
| 类别 | VER |
| 触发情境 | T-33按EXP-002建议为"低IV×震荡"复合布尔判据构造完整2×2真值表覆盖（族P/Q＝TT、族O＝TF、族Z＝FT、族N＝FF），实测四组合全命中，并设断言`exp002_boolean_truth_table_full_coverage`确认覆盖完整。外审变异E10（两子判据同时反向`<=`→`>=`）与E11（复合联结AND→OR）注入后，**四组合仍全覆盖、覆盖率断言不变量、两例均逃逸**——且classify()输出恰为本根Q4判据的输出本体，无任何独立验证通道 |
| 教训/问题 | 真值表覆盖完整只约束**输入空间是否张开**，对**实现是否读对了判据**无区分力。对称性变异（全体子判据同向翻转、联结词替换）在设计良好的对称输入族上恰好保持覆盖不变量。覆盖率越完整、断言越绿，虚假安全感越强 |
| 根因 | 覆盖率断言的判定对象是"各组合是否非空"，是输入分布的性质；实现正确性的判定对象是"每个具体输入映到哪个组合"，是逐点映射的性质。前者对后者的置换/翻转不敏感——两类性质在断言层被混同为同一种"验证" |
| 可迁移原则 | 双向反例覆盖须与**逐点期望值钉表**配对使用：为每个输入实例独立钉住其期望分类三元组（期望值自源文语义与input参数独立推导，不得取自被验实现的输出），覆盖率断言仅作输入设计自检、不入合格判定叙述链。单独的覆盖率断言不得被表述为对实现的验证 |
| 项目实例指针 | T-33外审报告v1.0 §1第三层E10/E11＋§2.4 P-3；裁决34-B2修复动作(b)（期望值钉表）为本条的即时兑现；EXP-002（本条为其强化候选：EXP-002管"input状态覆盖决定检出力上界"，本条管"覆盖本身不构成检出"） |
| 适用边界/反例 | (a) 覆盖率断言对**非对称**变异（单个子判据单向改动）仍可能有区分力——本条不主张覆盖率断言无用，主张其不充分；(b) 若期望值钉表已在场，覆盖率断言作为输入设计自检有独立价值，不应因本条移除；(c) 反例待寻：尚未遇到覆盖率断言单独击落对称变异的实例 |
| 状态 | **假设待验证**。当前证据＝T-33外审E10/E11两例实证（同根）；跨根验证待修复会话钉表落地后的增量复核重放 |
| 关联条目 | EXP-002（强化关系，见项目实例指针栏）。路由判定留痕：内容含布尔判据/分类等实现细节，但教训本体属验证方法论，依路由规则归EXP，不拆QT |

### EXP-004 · 切片产出的三层结论粒度（"能否量化识别"类提问的分层拆解）

| 字段 | 内容 |
|---|---|
| 日期/来源 | 20260727，裁决台会话（T-33收口裁定后KD追问初衷层问题："低IV+震荡这个特征最终是否可以被量化识别、这种打切片的动作最后一定需要有结论吗"）。三层拆分＝本会话回应时产出；**收录提出＝KD**（20260727） |
| 类别 | GOV（主）／PROC（次） |
| 触发情境 | T-33全流程收口：构造会话自记通过、外审判不通过、缺陷集中于验证结构与留痕纪律，而**原始语义问题的答案面貌不清**——从治理台账读不出"那件最初想搞清楚的事到底搞清楚了没有" |
| 教训/问题 | "X能否被量化识别"是复合提问，至少含三层，各层答案状态不同。**混层同时产生两类相反错误**：(i) 把第二层的强制开放误读为"切片没做完"，低估已达成的第一层；(ii) 为消除"没有结论"的不适而把第二层强行定案——即T-33之D-3（类三错判为类一）的**成因侧** |
| 根因 | 三层在提问语言中共用同一个动词"识别"，但**判定主体不同**：第一层（识别程序能否被构造并真跑）由代码真跑与独立复现判定；第二层（操作化与阈值是否唯一）由权威源文的**授权范围**判定——本例中00A§5行101禁止误用条款明文禁止硬阈值、只准以`parameter_slot_candidate`进入治理，即源文自身强制该层开放；第三层（被识别对象的经济语义）由尚未闭合的上游缺口判定。判定主体不同却共用一个问句，是混层的语言成因 |
| 可迁移原则 | ①回答"X能否被量化"前先拆判定主体，逐层给状态，不给合并答案；②切片的交付契约＝**窄问题的结论＋剩余开放面的完整地图**，不是"问题的答案"；③第二层的开放若由源文强制，则给出结论反而违规——此时"无结论"是合格态，须走登记（类三／TPL3）而非补齐；④混层检验的操作判据＝逐层问"这一层的结论由谁判定"，三层答案不同即须拆 |

### EXP-005 · 钉表的零点不随实现移动（对称比对的盲区与其唯一出口）

| 字段 | 内容 |
|---|---|
| 日期/来源 | 20260727，T-33增量复核会话（claude-opus-5，fresh context）正面记录P-4。**一手实证＝增量复核变异重放**；KD裁定收录＝裁决35-K |
| 类别 | VER |
| 触发情境 | T-33修复动作(b)"逐族期望值钉表"之裁定目的仅为消解E10/E11**单侧**逃逸（`classify()`输出本体零验证）。增量复核实测发现：钉表另外击落了**协同变异C1**（两侧`zone_state`边界读法同改）——41项断言中唯一FAIL即`expected_triple_pin_match_path_B`，全部数值比对与classify独立比对断言均通过 |
| 教训/问题 | 独立复算式的"两侧比对"，其判定零点是**两侧实现的共识**；当两侧沿同一语义选择同步漂移，零点随之移动，比对恒真——协同变异因此结构性逃逸。这不是实现缺陷，是比对方法的固有上限。**静态期望值钉表的零点锚在实现之外**（源文语义＋input参数独立推导），两侧同步漂移时钉表不动，故成为对称比对盲区的**唯一出口** |
| 根因 | 数值比对要求两侧计算同一个操作化候选才可比较——若允许两侧语义选择不同，比对本身失去意义。故"对协同变异有区分力"在结构上不可能由路径独立性提供。防护力的来源是**与实现的解耦程度**，不是断言数量、不是路径独立度、不是覆盖率 |
| 可迁移原则 | ①凡采用"独立复算＋两侧比对"的验证结构，须**同时**配置至少一条与两侧实现均解耦的外部锚（期望值钉表／解析不变量／源文语义直接断言），否则协同漂移零检出；②评估一条断言的防护力，问"它的零点锚在哪里"，不问"它覆盖了多少项"；③钉表的**粒度**决定其防护边界——只钉分类结果则数值层分叉可被分类层吸收（T-33实证：C3/C4b使rv_proxy数值分叉但三元组未翻转，仍逃逸），须按需下沉到数值层 |
| 项目实例指针 | T-33增量复核报告§2.5归因证据／§4.2击落表C1行／§7.4 P-4；裁决35-A（据此确立"协同变异无区分力＝数值比对方法固有上限、非D段②职责"之口径）；裁决34-B2(b)（钉表之原始裁定，目的仅为单侧逃逸）；观察项O-1→W-13(11)（钉表粒度口径成文） |
| 适用边界/反例 | (a) 钉表的独立性在**制品层面不可证伪**——"先手工推导后写入"与"先运行后转录"无法由交付物区分（裁决32-⑦所记审计能力上限），故本条主张的是**机制上的解耦**，其实际达成仍依赖构造纪律与顺序留痕（W-13(5)对冲项）；(b) 若操作化候选空间尚未闭合（本例即类三开放态），钉表锚定的是"当前候选读法下的真值"，候选一旦改判钉表须同步重推——钉表不解决候选空间问题，只解决同一候选下的漂移检出；(c) 本条不主张削减路径独立性要求：路径独立仍是**单侧**变异检出的必要条件（T-33之E1/E3/E4/E6/E12均由数值比对击落）；(d) 反例待寻 |
| 状态 | **已实证一例**（T-33 C1，程序化取证、归因明确）。跨根第二例待后续切片；证伪判据＝出现"两侧对称漂移被数值比对通道击落"之实例 |
| 关联条目 | **EXP-003（同域互补，一负一正）**：EXP-003指出覆盖率断言不构成对实现的验证（负面），本条指出解耦锚是对称比对盲区的出口（正面）；两条共同界定"断言的防护力来自零点位置，不来自数量或覆盖"。EXP-004（不同族）。路由判定留痕：本条实例含zone_state/rv_proxy等实现细节，但教训本体属验证方法论，依路由规则归EXP，不拆QT |

### EXP-007 · 裁决衡量四准则与两侧约束（策略构建与实盘落地为核心目标之裁决框架）

- **来源**：KD原创三准则（实现性/稳定性/一致性，围绕策略构建及实盘落地）→ 辅助裁决方操作化修订与增补呈裁 → KD裁定采纳（裁决64，20260804，骨架第三轮定案周期裁决台）。
- **目的论锚**：工程化之最终目标＝策略的稳定、一致运行；工程是策略的仪表与管道，非目的物（与宪法"价格在先、模型在后"同构；头号防御对象＝空转三环〔EXP-001〕）。
- **四准则（操作化定义）**
  1. **实现性**＝到下一个准入门的路径是否缩短。准入门序列＝G-1甲乙（骨架稳定N=2＋文本层pipeline贯通）→回测准入（L1/L2闭＋L3判据形态成文）→paper准入（L3注册反例集存活）→实盘准入（G-7偏差校准入安全边际）——合格判据链逐层准入视图（G-5扩充文本，裁决53-4d）。无门可挂之"进展"不计为实现性进展。
  2. **稳定性**＝分拆两对象：**构造期结构稳定**（骨架N计数、契约收敛、条目边界不漂移）与**运行期行为稳定**（判据跨regime存活、行为在声明边界内）。**防冻结偏置条款**：对凸性策略，运行稳定≠输出平滑——尾部行情中的剧烈但正确动作（触发开火、翼保持完整）恰是稳定的表现形式；"少改动"读法与凸性哲学冲突，禁用。修订通道成本（被证伪后改起来贵不贵）计入稳定性评估。
  3. **一致性**＝三层分列并排优先级：①语义一致（同一术语/量全域同义——审计表/术语册承载）；②数值一致（声明值＝计算值——指纹/C8声明面/#8对照批/verify承载）；③**跨环境一致（研究/回测/paper/实盘同一计算语义——最高权重子维；research-live gap为量化策略最高死亡率处，亦即自建引擎、排除vendor Greeks之原始动机）**。
  4. **可演化性**＝被证伪后能否便宜且安全地改：单点错误代价有界、修订成本低、修订通道畅通（归纳回流修正顶层为方法论自设义务）。服务凸性策略的工程自身应对新信息呈凸性。
- **两侧约束（守卫，非目标）**
  - **归因诚实**：每个"共性"携带成因出处——独立浮现型 vs 治理链驱动型（首个实例＝C8，IND3-17）。治理回声被误认为策略内在结构，是骨架喂给Phase B决策时最危险的污染源；四准则自身检测不到，须独立守卫。
  - **治理成本显性化**：每次裁决把治理开销列为显性代价（观察行承载）；对四准则零影响项走最低成本机械处理而非零处理（小不一致复利成语义漂移）；防"以一致性之名无限增管"。
- **准则冲突缺省模式**：**登记债务＋钉检查点**（范式＝T3-22声明值接收挂W-16 #8批）——一致性允许有账期，但每笔账必须有检查点与触发条件；**无检查点的债务不许记**；当场阻塞与静默放行均非缺省。
- **反冻结条款（对准则自身）**：准则按本项目对顶层哲学之同一方式对待——演绎统摄边界，操作定义从裁决实例反推并允许回流修正（首个回流实例＝IND3-07暴露三档标注缺跨批分布维度）。准则不冻结。
- **适用射程**：全部编号裁决之衡量与分组；辅助裁决方呈裁菜单须逐项标注触及准则与治理代价。
