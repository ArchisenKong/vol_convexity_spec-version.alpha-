## §1 丁-1 · G-B 端点口径对齐核证

**核证项来源**：自由度治理册v1.4 修订记录②「G-B·slot#1档案血缘标注补边：……**含端点口径对齐核验项，落#8桩替换/集成批**」。
**核证对象**：T3-17实现侧moneyness端点口径 vs T3-22已声明「端点计入within」之对齐实况。**仅出核证结果，不成文落写。**

### 1.1 两侧原文实录

**T3-22 声明面**（`一阶实体_T3-22_input_schema_v1_2` §9 边界口径声明，F-4断言基线）：

```
low <= moneyness <= high  → within（含两端边界）
moneyness > high          → above
moneyness < low           → below
```

**T3-17 实现侧**（`entity/harness.py` 行46–51）：

```python
if moneyness < band_low:      band_position = "below"
elif moneyness > band_high:   band_position = "above"
else:                          band_position = "within"
```

**T3-17 独立复算侧**（`verify/independent_recompute.py::band_position` 行27–30）：

```python
return ("below" if moneyness < band_low
        else ("above" if moneyness > band_high else "within"))
```

### 1.2 核证结果

**对齐成立。** T3-17两侧实现均以严格不等式判定 below/above，`within` 为其补集 ＝ `band_low ≤ moneyness ≤ band_high`，与T3-22声明之闭区间**逻辑等价、端点归属一致**（两端点均计入 within）。T3-17 harness侧与independent侧之间亦一致（记法不同、判定同构，与T3-22切片记录§7"band位置三处为代数等价重写、不计独立分叉"之申报自洽）。

### 1.3 附带发现（呈KD）

**T3-17 schema v2.2 无端点归属之显式成文句**。band相关表述见§1（"moneyness band位置判定（below/within/above，相对该翼声明的target_activation_band）"）与§4，**未载 `low <= m <= high` 或"含两端边界"之边界口径声明**。即：

- **实现面**：对齐成立（1.2实证）。
- **声明面**：T3-22有显式F-4基线，T3-17**缺**；端点归属在T3-17侧仅由实现之补集结构隐含。

此与裁决70 B-3之处置（"成文落写挂T3-17 schema下次自然再版"）**方向一致**——本核证为该落写提供实证依据：落写内容可直接取T3-22 §9三行口径，两侧已实证等价，落写为**成文追赶**而非口径变更。

### 3.3 人读结论（呈报态，不定性）

**字面层兼容、语义层存在标定基准缺环。**

三字段之**名称与形态**兼容（字段在场、两翼×9期、moneyness量纲一致）。但T3-17之响应比口径以 `target_vega_response_level`／`target_gamma_response_level`（21／24）为分母，该二值：

1. 由**T3-17自身 `declared_basis` 提供**，其取值系针对T3-17**现有手工时序**之标度标定；
2. **T3-22明文不供给**（schema §8「不涉及、不供给：`target_vega_response_level`／`target_gamma_response_level`（见§1越界声明）」；§1越界声明同）；
3. 全项目**无换源后重标之权威规则**（检索七根schema、撞墙清单族、自由度治理册slot#1档案，未见）。

**后果（若换源而不重标）**：`below_floor` 恒真、`consecutive_below_count` 单调累加至窗口上限、`wing_dullness` 判定**区分力归零**——即T3-17之核心判据在真实上游数据下失去可分辨性。

**射程边界**：本条**不质疑T3-17已收口判定**（其判定基于自身人造时序，实现层L1合格成立）；亦**不质疑T3-22已收口判定**（其输出为本根声明值，符合本根契约）。所述为**换源衔接时之口径缺环**，属断点二之未闭合面。

**候选定性方向（仅列，不主张）**：(a) 新增类二·缺定义型条目"响应比标定基准之换源重标规则"，供给方待定；(b) 归入自由度治理册slot#1占用者#1挂接参数面（G-A，`target_*_response_level` 与band四值同族，随宿主换装联动重置）；(c) 判为Phase B校准项（类三），阶段A不预设重标规则；(d) 判为T3-17实体边界问题（`target_*` 之供给方＝"动作/生命周期域既登记候选"，见T3-17 schema §1 v2.2注记），归该供给方建成时一并处置。
