## 对象语义（必填，B1）

TPL1-T76-01引擎＝**品种感知的自算 Greeks/定价供给物**之一阶实体。按品种路由适用定价模型，per-lot Greeks 与估值 V(t) 由自有统一算法计算，以消除回测（QC）与实盘（IBKR）数据源间的 Greeks 口径差异；QC/IBKR 仅供行情。

**供给方定位（契约⑥，既裁24-E3）**：仪表计算器，非定价真理源；Phase B 设计受宪法定价认识论章约束（消费通道＝审计表行94/95）。构造物零"应然价格/正确定价"宣称，不以模型输出裁决获利合法性（措辞审计断言 A6 在场）。

**下边界**：止于 per-lot 两层（`per_unit` / `per_lot`）。node 级聚合＝T-76 本职（裁决14），腿级聚合＝GK-31 本职，本实体均不做。不承载 identity/target review 判定或 target 变更之自动执行位（审计表行96，宪-ID-02，人工域，pipeline出口外）。

**实跑印证**：8 笔人造持仓覆盖六品种全域——现货（L01，长仓1000份）、现货ETF（L02，长仓200份）、指数（L03，长仓10份）、期货（L04，空仓4手×50）、欧式期权3笔（L05 长仓 call K=105/90D/σ=0.20；L06 空仓 put K=95/45D/σ=0.25；L08 空仓 call K=65/365D/σ=0.35）、美式期权1笔（L07 长仓 put K=110/181D/σ=0.30）。三情形各跑一遍（base／情景冲击 ΔS=−5%・Δσ=+3vol pts／时点推移 +10日），共 8×3×2层×6分量＝**288 项数值**全部实产，无空位、无 null。语义与实跑行为一致。

## 检验通道记录

**独立复算之路径独立性（何以核心分叉）**：
- **数据源独立**：`verify/independent_recompute.py` 只读 `entity/input_data.json`，不触碰被测侧任何产物。
- **计算核心分叉（非取字段/循环外壳分叉）**：被测侧五希腊由**闭式解析公式**给出（`math.erf` 入口）；独立侧五希腊**全部由估值函数之高精度数值微分求得**（`mpmath.diff`，dps=60；delta=∂V/∂S、gamma=∂²V/∂S²、vega=∂V/∂σ、theta=−∂V/∂T、rho=∂V/∂r），零解析希腊公式。两侧连"希腊是否由求导得出"这一层都不共享。该分叉同时直接验证契约①之"Greeks＝V之导数"语义与契约③之 raw 量纲（偏导定义本身即量纲声明）。
- 线性分支：被测侧浮点恒等映射，独立侧 `fractions.Fraction` 精确有理。日期差：被测侧手写 Rata Die 整数式，独立侧 `datetime.date` 序日。
- 共用原语仅限 Python 内置算术与 `json`（平凡 primitive）。

**判据基线独立解析（T3-03 缺陷F1 教训落实）**：`assert_check.py` 之全部结构性基线（顶层键集／记录键集／分量键集／六品种路由映射／可算性标注／未言明维度标注）均由脚本**程序化解析 `entity/input_schema.md` 之三个声明块与 ROUTE_DECLARATION 块**取得，无任何人工转抄常量。

**交付件自足性（W-13(6) 教训落实）**：`assert_check.py` 零 `/mnt/project/` 依赖、零包外路径、零行区间硬编码。量纲契约（T-76 schema 行80）以**指针**载于 `entity/input_schema.md`，其可证伪化由独立复算之偏导定义承担，而非源文行区间读取。
